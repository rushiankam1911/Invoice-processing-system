# 🧾 Invoice Processing System

A full-stack web application for managing invoice records, built using **Spring Boot** (Java) for the backend and **React** for the frontend.

---

## 🚀 Features

- Add, update, delete invoice entries
- Fetch and display invoices with filtering
- Backend REST APIs using Spring Boot
- Frontend interface using React
- Persistent storage with MySQL database

---

## 🛠️ Tech Stack

| Layer       | Technology           |
|-------------|----------------------|
| Frontend    | React, HTML, CSS     |
| Backend     | Spring Boot, Java    |
| Database    | MySQL                |
| Build Tools | Maven (or Gradle)    |
| Version Control | Git, GitHub     |
